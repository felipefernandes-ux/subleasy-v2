# Primeiro Pulso

**Um movimento visual sobre o instante anterior ao primeiro sinal: a linha ainda reta, o instrumento já ligado.**

Primeiro Pulso trata a ausência como prontidão, não como falta. Um campo vazio não é um erro de tela; é um aparelho calibrado esperando a primeira leitura. A forma diz isso antes de qualquer palavra: uma linha horizontal perfeitamente plana atravessa um campo escuro e, num ponto exato, deixa de ser contínua para virar tracejado, o trecho do tempo que ainda não aconteceu. A peça deve parecer feita com paciência obsessiva, cada medida conferida duas vezes, obra de quem domina o ofício.

O espaço é modular e silencioso. Um campo dominante no alto, dois blocos de apoio embaixo, alinhados pela mesma margem e separados pelo mesmo intervalo, como salas de um mesmo andar. Nada se sobrepõe, nada encosta na borda. O vazio entre os blocos é arquitetura. A composição precisa transmitir horas de ajuste fino: raios iguais, espessuras iguais, um único módulo regendo tudo.

A cor é escassa e tem função. Violeta profundo é o campo da atenção, onde o pulso vai aparecer. Cinzas frios, quase papel, guardam o que ainda está livre: células de uma semana sem marcas, barras que um dia serão números. Um único contorno violeta numa célula vazia indica onde a primeira marca deve cair. Um único ponto de menta, com um halo tênue, marca o agora, a fronteira entre o traço firme e o tracejado. Ele aparece uma vez, e por isso pesa. A paleta deve parecer calibrada com paciência de laboratório.

O ritmo é o da semana: sete colunas, quatro faixas, repetidas com precisão de régua até virarem textura. A hierarquia vem do contraste entre o campo escuro, firme, e os blocos claros, sussurrados. O texto é quase inexistente, etiquetas monoespaçadas nas margens, coordenadas de um registro de observação, e só onde ancoram o que a forma já mostrou.

O acabamento é o argumento. Traços de espessura única com pontas arredondadas, tracejado de cadência exata, cantos suaves sem serrilhado, alinhamentos derivados de uma mesma unidade. O resultado deve parecer inevitável: um instrumento de precisão em repouso, bonito o bastante para ser exposto, execução de mestre, sem um detalhe sobrando e nenhum faltando.
